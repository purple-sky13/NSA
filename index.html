NSA CSV Anomaly Detector

A local, browser-based file anomaly detector using entropy, column count, and the Negative Selection Algorithm.

1. Train the detector

Select at least 3 known-normal CSV files. Their entropy and column counts will be used to establish the normal regions and generate detectors.

2. Scan a CSV file

Upload a new CSV file to check whether its features fall within the learned normal regions or match a surviving detector.

Model settings

  • Entropy tolerance around each normal example: ±0.2 bits per byte.
  • Normal column-count tolerance: ±0.5 columns.
  • Detector recognition radius: ±0.2 entropy and ±0.5 columns.
  • Candidate detector attempts: 15,000.
  • Detector storage: browser memory only; refreshing clears it.

The model uses raw-byte entropy. CSV column count is obtained from the first non-empty record, with quoted commas handled. Use consistently encoded CSV files for meaningful comparisons.
